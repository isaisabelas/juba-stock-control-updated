# Metodologia e Plano de Acao - Juba Estoque

## 1. Abordagem adotada

Foi utilizada uma abordagem incremental, com ciclos curtos de:

1. levantamento de necessidade
2. modelagem funcional
3. implementacao
4. validacao tecnica e visual
5. documentacao

## 2. Etapas executadas

### Etapa 1 - Analise do problema

- mapeamento das dores de controle de estoque
- definicao de escopo minimo viavel
- priorizacao de entregas

### Etapa 2 - Modelagem

- definicao de casos de uso
- definicao de entidades de dados
- organizacao de rotas e modulos

### Etapa 3 - Desenvolvimento

- frontend React com componentes reutilizaveis
- backend Express com rotas por contexto
- persistencia SQLite e regras de negocio

### Etapa 4 - Qualidade

- correcao de inconsistencias de layout
- separacao entre Dashboard e Produtos
- validacao por `npm run build`

### Etapa 5 - Consolidacao documental

- revisao completa dos arquivos markdown
- alinhamento entre documentacao e implementacao
- preparo de pacote entregavel para avaliacao

## 3. Criticos de sucesso da metodologia

- rastreabilidade entre requisito e funcionalidade
- coerencia entre interface, API e banco
- build sem erro para entrega
- documentacao objetiva e atualizada

## 4. Resultado metodologico

A metodologia permitiu evolucao continua do projeto, com correcao de desvios de escopo e consolidacao final em uma versao funcional, testavel e documentada.
